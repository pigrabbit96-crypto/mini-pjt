## 6. 발견한 문제

- 이동 경로 단정: 사람 판정에서 E03이 "맞아요, 꽤 많이 갔습니다!"로 실패했고, P02·E01·E02도 "수도권·광역시로 이동", "서울로 모이는 흐름"처럼 이동 방향을 짐작하는 표현이 있었다.
- Judge와 사람의 판정이 이동 경로 단정에서 엇갈렸다. Judge는 P02의 "수도권·광역시로 이동하는 경우가 많다"를 금지 항목 위반으로 불통과 처리했지만, E03의 "꽤 많이 갔습니다"는 통과로 봤다. 같은 문제를 서로 다른 건에서 잡았으므로, 이 문제는 판정에 기대지 말고 규칙(파이썬 점검)으로 막아야 한다.
- Faithfulness가 1보다 낮은 건(P01, P04)은 모두 모델이 도구 값으로 직접 만든 해석이다. P01의 "20%를 초과하면 초고령사회"는 이 답변에서 문서를 검색하지 않아 근거가 없고(문서 정의는 '20% 이상'), P04의 "약 6명에 1명꼴"은 직접 계산한 비율이다. 둘 다 1,000 미만 수라 숫자 검증 대상에서 빠진다.
- 정확한 값 앞의 어림 표현(P02 "약 2,461명이 전남을 떠났을 가능성")이 숫자 검증을 통과했다. 값은 정확해 판정에는 영향이 없다.
- Answer relevancy는 거절 답변(N01·N02 0.0, G01 0.068)과 짧은 후속 질문(E01 "그럼 서울은?" 0.26)에서 낮다. RAGAS 정의상 거절은 질문에 '답하지 않은' 것으로, 맥락에 기대는 짧은 질문은 생성 질문과 덜 비슷하게 나온다. 품질 문제라기보다 지표의 특성이다.
- 평가 밖 점검에서 모델 호출이 실패하면 응답이 answer·contexts·trace 세 키 없이 {"detail": ...}만 나가는 것을 발견했다.
